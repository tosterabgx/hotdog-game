# Eat hotdogs!

**Snapchat-like game made using opencv and mediapipe 🌭**

Game for a party - who eats more hotdogs

## Installation & Usage

> [!IMPORTANT]  
> Python 3.8 to 3.11 is required (mediapipe issue)

1. Clone the repo
   ```sh
   git clone https://github.com/tosterabgx/hotdog-game.git && cd hotdog-game
   ```
2. Create a venv and activate it
   ```sh
   python -m venv .venv && source .venv/bin/activate
   ```
3. Install required packages
   ```sh
   pip install mediapipe==0.10.21 opencv-python pygame
   ```
4. Run the game
   ```sh
   cd hotdog-game
   python main.py
   ```
